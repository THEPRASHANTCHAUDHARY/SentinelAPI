02 / CAPABILITIES

Test the
logic
behind APIs.

SentinelAPI focuses on high-impact API security problems where a request can be syntactically valid but still violate authorization or expose more information than intended.
01 / AUTHORIZATION

BOLA / IDOR

Manipulate resource identifiers across authorized sessions and verify whether one user can access another user's resource.

02 / DATA

Excessive exposure

Inspect response payloads for sensitive or internal fields that should not be returned to the tested client.

03 / AUTH

Auth misconfiguration

Check supported endpoints for weak or missing authentication behavior.

04 / TRAFFIC

Rate-limit weakness

Exercise repeated requests and identify endpoints that do not demonstrate expected throttling behavior.

05 / INPUT

OpenAPI ingestion

Start from an authorized OpenAPI or Swagger definition to discover the target's API surface.

06 / REPORTING

Evidence-first findings

Return severity-ranked findings with affected endpoint details and reproducible security-test context.

Security
without the black box.
