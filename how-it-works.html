The security workflow is deliberately simple: ingest an authorized OpenAPI definition, discover the surface, run controlled tests, verify behavior and produce findings your team can act on.

Load OpenAPI / Swagger served by the configured local sandbox.

02

Build the endpoint inventory and identify testable resources.

03

Test safely

Run supported authorization, data exposure, authentication and rate-limit checks.

04

Verify

Compare expected and observed behavior and reduce false positives.

05

Report

Show severity, evidence and reproducible security-test context.
